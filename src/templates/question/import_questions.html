متطلبات تنسيق الملف

يجب أن يحتوي الملف على الأعمدة التالية بالترتيب:

  1. Course Name (اسم المنهج - مطلوب)
  2. Unit Name (اسم الوحدة - مطلوب)
  3. Lesson Name (اسم الدرس - مطلوب)
  4. Question Text (نص السؤال - اختياري في حال وجود صورة)
  5. Question Image URL (رابط صورة السؤال - اختياري)
  6. Option 1 Text (نص الخيار 1 - اختياري في حال وجود صورة)
  7. Option 1 Image URL (رابط صورة الخيار 1 - اختياري)
  8. Option 2 Text (نص الخيار 2 - اختياري في حال وجود صورة)
  9. Option 2 Image URL (رابط صورة الخيار 2 - اختياري)
  10. Option 3 Text (نص الخيار 3 - اختياري)
  11. Option 3 Image URL (رابط صورة الخيار 3 - اختياري)
  12. Option 4 Text (نص الخيار 4 - اختياري)
  13. Option 4 Image URL (رابط صورة الخيار 4 - اختياري)
  14. Correct Option Number (رقم الخيار الصحيح - مطلوب: 1، 2، 3، أو 4)
  15. Explanation (شرح الإجابة الصحيحة - اختياري)

هام:

  • يجب أن يحتوي الصف الأول على أسماء الأعمدة باللغة الإنجليزية تمامًا كما هي مذكورة أعلاه.
  • مطلوب خياران على الأقل (نص أو صورة) لكل سؤال.
  • يجب أن تتطابق أسماء المنهج والوحدة والدرس مع الأسماء الموجودة في النظام بالضبط. انقر هنا لتنزيل قائمة المناهج والوحدات والدروس المتاحة.
  • تأكد من أن روابط الصور صالحة ويمكن الوصول إليها بشكل عام.
