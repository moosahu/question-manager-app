# ملف list.html المحدث - إضافات نظام المنع ## التعديلات المطلوبة على ملف templates/question/list.html ### 1. إضافة أزرار التحكم في أعلى الصفحة **ابحث عن:** ```html
إضافة سؤال جديد
``` **استبدله بـ:** ```html
إضافة سؤال جديد
``` --- ### 2. إضافة عمود Checkbox في الجدول **ابحث عن:** ```html رقم السؤال ``` **استبدله بـ:** ```html رقم السؤال ``` --- ### 3. إضافة Checkbox لكل سؤال **ابحث عن:** ```html {{ start_num + loop.index0 }} ``` **استبدله بـ:** ```html {{ start_num + loop.index0 }} ``` --- ### 4. إضافة مؤشر بصري للأسئلة الممنوعة **ابحث عن:** ```html {% if question.question_text %} {{ (question.question_text | truncate(100)) }} ``` **استبدله بـ:** ```html {% if question.is_blocked %} ممنوع {% endif %} {% if question.question_text %} {{ (question.question_text | truncate(100)) }} ``` --- ### 5. إضافة أزرار منع/إلغاء منع فردي **ابحث عن:** ```html تعديل ``` **استبدله بـ:** ```html تعديل {% if question.is_blocked %} {% else %} {% endif %} ``` --- ### 6. إضافة JavaScript في نهاية الملف **أضف قبل `{% endblock %}`:** ```html ``` --- ## ملخص التعديلات 1. ✅ أزرار في الأعلى: منع المحدد، إلغاء منع المحدد، تحديد الكل 2. ✅ Checkbox في رأس الجدول لتحديد الكل 3. ✅ Checkbox بجانب كل سؤال 4. ✅ مؤشر بصري (badge) للأسئلة الممنوعة 5. ✅ خلفية صفراء للصفوف الممنوعة 6. ✅ أزرار منع/إلغاء منع فردي لكل سؤال 7. ✅ JavaScript للتعامل مع API --- ## النتيجة النهائية - يمكن تحديد عدة أسئلة ومنعها دفعة واحدة - يمكن منع/إلغاء منع سؤال واحد مباشرة - الأسئلة الممنوعة تظهر بخلفية صفراء مع badge "ممنوع" - واجهة سهلة وسريعة
